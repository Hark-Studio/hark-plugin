# Grok Bot listing

Status on 2026-10-03: path not verified. Do not claim Grok Bot availability.

What is known:
- Grok Bot has a Marketplace in its sidebar ("Marketplace → Your plugins → Manage plugins and skills") for connectors and packaged skills.
- Grok Build's catalog is `xai-org/plugin-marketplace` on GitHub. Whether Grok Bot reads that catalog, a Cursor-style marketplace, or a separate submission form is not documented publicly as of this date.
- Today a Grok Bot user connects Hark by asking the bot to add the MCP server with a Hark personal access token (harkstudio.io/how-it-works/connect/grok-bot). The `hark-bot-notes` skill is written for that case.

To verify:
1. Open the Marketplace in Grok Bot and check whether the Grok Build plugins (for example `neon`, `axiom`) appear. If they do, the `xai-org/plugin-marketplace` entry covers Grok Bot too.
2. Otherwise ask xAI (the marketplace repo's issues, or the console.x.ai support path) for the submission route and record the answer in Hark as a decision.
